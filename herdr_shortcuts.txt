HERDR SHORTCUTS (Prefix: Ctrl + Space)

PANES
prefix + h / alt + enter    split horizontal
prefix + v / alt+shift+ent  split vertical
prefix + x / alt + esc      close pane
prefix + z                  zoom pane
alt + h/j/k/l               focus pane
ctrl+alt+shift+arrows       resize pane

TABS
prefix + c                 new tab
prefix + k                 close tab
prefix + r                 rename tab
prefix + 1..9              switch tab
prefix + n/p               next/prev tab
prefix + shift+left/right  move tab

WORKSPACES
ctrl + shift + 1..9        switch directly to workspace 1..9
ctrl + shift + tab         previous workspace
prefix + shift+c           new workspace
prefix + shift+k           close workspace
prefix + shift+n/p         next/prev workspace

GHOSTTY
ctrl + shift + tab         released in Ghostty for Herdr

GENERAL
prefix + q                 reload config
prefix + ?                 help
prefix + d                 detach
prefix + [                 copy mode
